PROMPT 0 — GLOBAL DESIGN SYSTEM (run first)
================================================================================

Design a mobile design system for "NetLinq", an Android QoE network monitoring
app for Cameroon. Material Design 3 inspired, clean, trustworthy, not flashy.

COLOURS:
  Primary teal: #0D9488 (light mode buttons), #5EEAD4 (dark mode accent)
  Background light: #F8FAFC | Surface light: #FFFFFF
  Background dark: #0F172A | Surface dark: #1E293B
  Text primary light: #0F172A | Text secondary light: #475569
  Text primary dark: #F8FAFC | Text secondary dark: #94A3B8
  Quality Good: #22C55E | Fair: #F59E0B | Poor: #EF4444

TYPOGRAPHY (Roboto / system sans):
  Headline Large: 32sp Bold — app titles
  Headline Medium: 26sp Bold — hero values
  Title Large: 20sp SemiBold — section headers
  Title Medium: 16sp SemiBold — card titles
  Body Large: 16sp Regular — intro paragraphs
  Body Medium: 14sp Regular — descriptions
  Label Large: 14sp Medium — badges, labels
  Label Medium: 12sp Medium — captions

COMPONENTS:
  - Cards: white/dark surface, 20px corner radius, subtle 2dp shadow
  - Primary button: filled teal, white text, full width or half width, pill shape
  - Outlined button: teal border, teal text
  - Quality badge: pill shape, coloured text on 15% opacity tinted background
  - Stat chip: 16px radius, tinted background 10% opacity, value bold on top
  - Star rating: 5 stars, filled teal when selected, outline grey when empty
  - Step indicator: 5 horizontal bars, 4px height, filled teal = completed
  - Bottom nav: 4 items with icon + label, Material 3 style
  - Bottom sheet: rounded top corners, drag handle, overlays main content

SPACING: 20–24px screen padding, 16–20px between sections, 16px card inner padding.

TONE: Privacy-first, anonymous (no login), professional, accessible, simple.
